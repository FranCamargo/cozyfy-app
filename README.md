# cozyfy

Aplicativo mobile criado com Expo (React Native) e TypeScript.

## Scripts

- `npm start` – inicia o Metro bundler (Expo)
- `npm run android` – abre o app no Android (emulador ou dispositivo)
- `npm run ios` – abre o app no iOS (requer macOS)
- `npm run web` – abre a versão web

## Estrutura principal

- `App.tsx` – ponto de entrada do app, carregando a Home
- `src/screens/HomeScreen.tsx` – tela inicial com layout base do Cozyfy

## Executando o projeto

1. Instale as dependências (se necessário):
   - `npm install`
2. Inicie o projeto:
   - `npm start`
3. Use o app Expo Go ou um emulador para visualizar o cozyfy.
